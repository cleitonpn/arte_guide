# Modelos 3D do estande

Faça upload do arquivo `.glb` do estande nesta pasta pelo GitHub
(Add file → Upload files), na branch `claude/wonderful-allen-clr06m`.

Recomendado: reduzir para < 25 MB antes do upload (limite do upload via web).
O arquivo será otimizado (Draco + redução de texturas) antes de entrar no tour.
